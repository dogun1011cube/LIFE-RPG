# PROJECT ETERNUM

오픈월드 RPG + 건축 + 문명 건설 게임. TypeScript · Three.js · React · Vite로 만들었으며 브라우저에서 바로 실행됩니다.
외부 3D 모델·텍스처·사운드 파일 없이 지형, 캐릭터, 몬스터, 건축물, 텍스처, 효과음을 모두 코드로 절차적으로 생성합니다.

현재 단계: **PHASE 5 완료 (v0.5)** — PHASE 1(플레이 가능한 3D 기반), PHASE 2(스킬·마법·막기·던전), PHASE 3(구조 안정성·설계도·요새·휴식), PHASE 4(정착지·주민·직업·생산)에 이어, 연구와 시대 발전, 금고와 세금, 생산 체인, 주택, 밤의 습격과 수비대, 주민 길 찾기로 마을을 소도시와 도시로 키우는 문명 시스템을 더했습니다.

## 실행 방법

```bash
npm install
npm run dev          # http://localhost:5173 접속
```

- 배포용 빌드: `npm run build` → `dist/` (상대 경로 빌드라 GitHub Pages 같은 하위 경로에서도 동작)
- 빌드 미리보기: `npm run preview`
- 타입 검사: `npm run typecheck`
- 권장 환경: WebGL2를 지원하는 최신 Chrome / Edge / Firefox. 느리면 `설정 → 그래픽 품질 → 낮음`.

## PHASE 3 — 건축 고도화

| 기능 | 내용 |
| --- | --- |
| 구조 안정성 | 땅에 닿은 조각은 100%. 위로 쌓으면 조금씩(나무 88%·돌 93%·대리석 95%), 옆으로 뻗으면 크게(62%·72%·78%) 줄어듭니다. 15% 미만은 설치할 수 없고, 받침을 철거하면 떠 있던 부분이 무너지며 재료 절반이 떨어집니다. 바라보는 조각의 안정도가 색(초록·노랑·빨강)으로 표시됩니다 |
| 설계도 | P로 바라보는 건물과 연결된 조각 전체를 이름 붙여 저장 → 설계도 분류에서 골라 회전하며 미리보기 → 한 번에 건설(전체 재료 소모, 겹침·지형 검사). 이 브라우저의 모든 저장 슬롯에서 공유. 기본 설계도 '작은 오두막' 포함 |
| 새 건축물 | 성벽(높이 5m, 위를 걸을 수 있음), 성탑(높이 7.5m, 꼭대기 화로가 반경 34m를 밝혀 밤의 괴물 차단), 나무 다리(6m), 흙길·돌길(지형을 따라 깔리고 위에서 이동 속도 +30%), 대리석 7종, 책장·카펫·화분·가로등 |
| 건축 재료 | 석재 벽돌(작업대에서 제작) → 대리석 건축물과 성벽·성탑 |
| 편의 기능 | Q 재료 바꾸기, Z 옮기기, 0키로 10번째 선택 |
| 실내와 휴식 | 지붕 아래에서 불(횃불·모닥불·가로등 등) 곁에 6초 머물면 '휴식'(스태미나 회복 +30%, 체력 회복 +1.5/초, 경험치 +10%). 주변 가구 종류가 많을수록(안락도) 오래 지속. HUD에 실내·안락도 표시 |
| 퀘스트 | 따뜻한 보금자리, 길을 내다, 설계자, 요새 건설 |

## PHASE 4 — 마을

| 기능 | 내용 |
| --- | --- |
| 정착지 세우기 | '따뜻한 보금자리' 퀘스트를 마치면 마을 회관이 해금됩니다. 회관을 지으면 반경 45m가 정착지가 되고(한 세계에 하나), 마을 건물은 이 반경 안에만 지을 수 있습니다. 회관을 철거하면 다시 지을 때까지 정착지가 멈춥니다(주민과 창고는 유지) |
| 마을 건물 | 마을 회관, 창고, 밭, 벌목장, 갱도, 우물(정착지 1단계), 시장 가판대(2단계) |
| 주민 | 빈 침대가 있고 음식·행복도 조건을 채우면 40초마다 새 주민이 찾아옵니다. 침대 1개 = 집 1채. 이름·옷·머리색이 제각각이고, 머리 위에 이름표가 뜹니다. E로 대화하면 상태에 맞는 대사(배고픔·집 없음·일 없음·행복)와 직업 변경 버튼이 나옵니다 |
| 일과 AI | 밤(21:30–6:00)에는 자기 침대로 가서 잠, 낮(6:00–18:30)에는 일터로 출근, 저녁에는 회관 주변을 거닐거나 모여서 이야기합니다. 걸려서 3초 이상 못 움직이면 목적지로 순간 이동합니다 |
| 직업과 생산 | 농부(밭: 밀), 나무꾼(벌목장: 목재), 광부(갱도: 돌, 가끔 구리 광석), 장인(작업대: 돌 → 석재 벽돌), 요리사(모닥불: 밀 → 빵, 날고기 → 구운 고기), 상인(시장: 은화, 거래 가능). 일터 하나에 한 명. 실제로 일터에 도착해 일하는 동안에만 20초마다 생산하고, 결과는 마을 창고로 들어갑니다. 행복도가 높으면 추가 생산, 낮으면 일을 빼먹습니다. '자동 배정' 버튼 제공 |
| 창고와 식량 | 창고 용량 100 + 창고 건물마다 300. 마을 탭에서 맡기기·꺼내기. 매일 아침 주민마다 음식 1인분(빵·구운 고기 = 2, 열매·밀·날고기 = 0.5)을 먹고, 모자라면 굶습니다 |
| 행복도 | 침대, 지붕 있는 집, 침대 주변 가구, 식사, 직업, 마을 장식(화분·가로등·카펫 등), 길(8칸 이상)이 올리고, 굶주림과 집 없음이 내립니다. 행복도 15 미만으로 이틀이 지나면 주민이 떠납니다 |
| 성장 단계 | 1 작은 정착지(최대 4명) → 2 마을(주민 4·창고·일터 2종 이상, 최대 8명) → 3 발전된 마을(주민 8·행복도 60·시장·정착 헌장 사용, 최대 14명). 단계가 오르면 배너와 함께 새 건축물이 해금됩니다 |
| 시장 | 상인이 일하는 시장 가판대가 있으면 열림. 은화로 빵·물약·석재 벽돌·구리 주괴·가죽·공명 수정 구매, 소지품 판매(기준가의 60%) |
| 밭 | 밭은 혼자서도 천천히(5분) 자라고 농부가 돌보면 빨리 자랍니다. 다 자란 밭은 E로 직접 수확할 수도 있습니다. 작물이 자라는 모습이 보입니다 |
| 마을 탭 (H) | 주민 목록(상태·직업 선택), 일터 현황, 창고, 시장, 성장 단계, 마을 기록. 지도와 미니맵에 회관 위치·정착지 반경·주민 위치 표시 |
| 퀘스트 | 정착지 세우기 → 첫 주민 → 일하는 마을(주민 3명 고용) → 마을로 성장 → 첫 거래 → 발전된 마을 |
| 아이템 | 밀, 빵, 은화 |

## PHASE 5 — 도시와 문명

| 기능 | 내용 |
| --- | --- |
| 연구와 시대 | "마을" 단계에서 연구소를 짓고 학자를 배정하면 연구 점수가 쌓입니다(연구소 6m 안의 책장 하나마다 +1, 최대 2). 공명 수정·고대 파편·어둠의 정수·망각의 서를 기증해도 점수를 얻습니다. [L] 문명 창에서 연구 점수와 금고 은화로 기술을 삽니다. 개척 시대 → 청동 시대 → 왕국 시대, 3시대 15개 기술(시대를 넘으려면 이전 시대 기술 3개 필요) |
| 기술 효과 | 윤작법(밀 +2, 밭 성장 2배), 기록 문자(연구 +1), 목공(제재소·판자), 주거 계획(목조 주택), 화폐(세금), 제련술(용광로), 도구 제작(대장간·도구 꾸러미), 민병대(경비 초소), 석조 건축(석조 주택), 교역로(시장 가격), 축성술(궁수탑·경비병 강화), 도시 건축(분수 광장·장식 상한), 행정(세금 +50%) |
| 금고와 세금 | 마을 금고(상인 수입·세금이 쌓이고 연구비·급료가 나감). 플레이어 은화를 맡기거나 꺼낼 수 있음. 세율 없음/낮음/보통/높음 — 높을수록 수입이 늘고 행복도가 떨어짐. 경비병 급료 하루 2 은화, 못 받으면 일을 쉼. 문명 창에 하루 예상 수지 표시 |
| 생산 체인 | 목수(제재소: 목재 3 → 판자 2), 제련공(용광로: 구리 광석 2 + 목재 1 → 구리 주괴), 대장장이(대장간: 주괴 + 판자 → 도구 꾸러미). 창고에 도구 꾸러미가 있으면 농부·나무꾼·광부 생산 +2(꾸러미 하나로 5번). 판자·도구 꾸러미는 작업대에서 직접 만들 수도 있음 |
| 주택 | 목조 주택(주민 2명)·석조 주택(4명). 지붕·가구가 갖춰져 행복도가 높고, 침대에서 자던 주민은 빈 주택으로 이사합니다. 밤이면 주민이 문으로 들어가고 창에 불이 켜집니다 |
| 밤의 습격 | "마을" 단계부터 2~4일마다 아침에 경보(종소리)가 울리고 밤 22시에 괴물 무리(늑대, 떠도는 해골, 소도시부터 골렘)가 몰려옵니다. 괴물은 가까운 플레이어·경비병·밖에 있는 주민을 공격하고, 막는 이가 없으면 회관에서 창고와 금고를 약탈합니다. 주민은 집으로 대피하고, 맞아서 쓰러진 주민은 아침에 회복하거나 [E]로 일으켜 세울 수 있습니다. 모두 쓰러뜨리면 방어 성공, 새벽까지 버티면 남은 괴물이 달아납니다. 멀리 있을 때 온 습격은 수비력(경비병·궁수탑)과 비교해 자동으로 결판납니다 |
| 수비대 | 경비병(구리 검·갑옷)은 낮 12시~아침 7시 초소 주변을 순찰하다 18m 안의 괴물과 싸우고, 습격 때는 마을 전체를 지킵니다. 궁수탑은 반경 24m의 괴물에게 자동으로 화살을 쏩니다. 수비대가 쓰러뜨린 괴물은 경험치 절반 |
| 주민 길 찾기 | 정착지 주변 1m 격자에 A* 경로 탐색. 벽·건물·나무·물·절벽을 피해 돌아가고, 길(도로)을 더 좋아하며, 문을 열고 지나간 뒤 닫습니다. 걸림 순간 이동은 최후의 수단으로만 남김 |
| 성장 단계 | 4 소도시(주민 14 · 청동 시대 · 경비 초소 · 행복도 55, 반경 60m, 최대 22명) → 5 도시(주민 22 · 왕국 시대 · 행정 · 분수 광장 · 행복도 60, 반경 75m, 최대 32명) |
| 문명 창 (L) | 시대, 연구 점수, 금고(맡기기/꺼내기), 기술 트리(연구 가능/잠김 이유 표시), 재정, 방어 현황, 유물 기증. HUD 상단에 습격 예고·진행 표시 |
| 건축물 | "도시" 분류: 연구소, 제재소, 용광로, 대장간, 경비 초소, 궁수탑, 목조 주택, 석조 주택, 분수 광장 |
| 퀘스트 | 지식의 등불 → 청동 시대 → 소도시 → 왕국의 기틀 → 빛나는 도시, 마을 금고, 장인의 사슬, 마을 수비대 |
| 버그 수정 | PHASE 4에서 건축 메뉴의 분류 목록에 "마을"이 빠져 있어 실제 플레이로는 마을 건물을 고를 수 없던 문제 |

## 게임 흐름 (시스템 연결)

섬에 표류 → 나무·돌·섬유 채집 → 돌도끼·돌곡괭이 제작 → 슬라임 사냥 → 작업대를 지어 돌검 제작 → 토대·벽·문·지붕·침대로 집 건축(침대 = 부활 지점, 밤에 잠자기) →
고원에서 구리 채광(광석을 얻으면 화로 제작법 발견) → 화로에서 주괴 제련 → 구리 장비 → 선돌 비문이 신전 위치를 지도에 표시 →
감시탑 보물상자의 고대 파편 + 골렘/수정 골짜기의 공명 수정 + 밤의 도깨비불이 남기는 어둠의 정수 → 고대 인장 제작 →
가라앉은 신전의 제단에서 폐허의 수호자 소환·처치 → 정착 헌장 획득.
집을 지은 뒤에는 마을 회관으로 정착지 선포 → 침대를 놓아 주민을 받고 → 밭·벌목장·갱도에 배정 → 창고에 쌓인 밀을 요리사가 빵으로 → 주민 4명과 창고로 '마을' 단계 → 시장에서 거래 → 정착 헌장과 행복도 60으로 '발전된 마을'.
'마을'이 되면 연구소와 학자로 기술 연구 → 주택으로 인구 증가, 화폐와 세금으로 금고 → 청동 시대의 제련·대장간 생산 체인과 경비병 → 밤의 습격 방어 → '소도시' → 왕국 시대의 궁수탑·분수 광장·행정 → '도시'.

시스템 간 연결 예:
- 불빛(횃불·모닥불·화로)과 침대 주변에는 밤의 괴물이 생기지 않음 → 건축이 생존을 돕는다.
- 제작 시설은 건축물 → 건축이 제작 단계를 연다.
- 새 재료를 처음 얻거나, 레벨이 오르거나, 고대 기록을 읽으면 제작법·건축물이 해금된다.
- 지역마다 자원과 몬스터가 다르고, 밤에는 다른 몬스터가 나온다.
- 마을은 건축 시스템 위에 있다: 침대가 집, 작업대·모닥불이 장인·요리사의 일터, 장식·길·지붕이 주민 행복도를 올린다.
- 주민이 생산한 석재 벽돌·목재가 다시 대리석 건축과 요새 건설의 재료가 되고, 던전 보상(정착 헌장)이 마을의 마지막 단계를 연다.
- 탐험에서 얻은 유물(공명 수정·고대 파편)이 연구 점수가 되고, 연구가 새 건물·직업·제작법을 연다.
- 경제(세금·상인 수입)가 연구비와 경비병 급료를 대고, 수비대가 습격으로부터 창고와 주민을 지킨다. 성벽·성탑·횃불 같은 PHASE 1~3 건축물도 방어에 그대로 쓰인다.

### 데이터 수정

밸런스와 콘텐츠는 `src/game/data/`의 배열만 고치면 됩니다. 예를 들어 새 무기는 `items.ts`에 항목을, 제작법은 `recipes.ts`에 추가하면 UI·저장·해금이 자동으로 따라옵니다.
적은 `enemies.ts`(공격 패턴 목록 포함), 퀘스트는 `quests.ts`(목표 타입: 획득/제작/처치/건설/설치 개수/발견/레벨/카운터), 건축물은 `buildables.ts` + `systems/BuildMeshes.ts`(형태)입니다.
직업·성장 단계·음식 가치·시장 물품·세율·기증 유물·주민 이름과 대사는 `village.ts`, 기술 트리와 시대는 `techs.ts`에 있습니다.

### 멀티플레이 확장을 위한 설계

- 진행 상황은 렌더링 객체와 분리된 순수 JSON(`GameState`)으로만 저장됩니다. 플레이어 상태(`PlayerState`)와 세계 상태(건축물, 고갈된 자원, 시간, 정착지·주민·창고)가 나뉘어 있어 서버 권한 모델로 옮기기 쉽습니다.
- 정착지 시뮬레이션(생산·식량·행복도·도착)은 상태 JSON만 바꾸고, 주민 3D 모델은 그 상태를 따라 그려지기만 합니다. 서버에서 시뮬레이션을 돌리고 클라이언트는 표시만 하는 구조로 옮길 수 있습니다.
- 저장 입출력은 `systems/Save.ts` 한 곳에만 있어 서버 저장 API로 바꾸기 쉽습니다.
- 세계는 시드 기반 결정적 생성이라, 클라이언트끼리는 시드와 변경 사항(건축물, 고갈된 노드)만 동기화하면 됩니다.

## 알려진 한계

- 스킬 수치와 던전 난이도는 자동 테스트로만 확인했습니다. 실제 플레이 감각에 맞춘 밸런스 조정이 필요할 수 있습니다.
- 던전은 아직 1곳이고, 들어갈 때마다 몬스터와 퍼즐이 초기화됩니다(보물상자는 한 번만).
- 적 AI에 경로 탐색(navmesh)이 없습니다. 막히면 옆으로 우회하는 간단한 조향만 있어, 복잡한 지형에서는 걸릴 수 있습니다.
- 구조 안정성은 이번 버전부터 적용되며, 이전 버전에서 지은 불안정한 건물은 불러올 때 무너뜨리지 않습니다(그 받침을 철거할 때만 무너짐).
- 설계도는 브라우저 저장소에 보관되므로 다른 브라우저나 기기로는 옮겨지지 않습니다.
- 날씨(비·안개)는 아직 없습니다.
- 주민의 A* 길 찾기는 정착지 반경(+14m) 안에서만 동작합니다. 그 밖에서는 곧장 걷고, 오래 막히면 순간 이동합니다. 습격 괴물을 포함한 적 AI에는 여전히 경로 탐색이 없어 성벽에 걸릴 수 있습니다.
- 주택은 내부가 없는 하나의 건물입니다. 주민은 문 앞에서 집 안으로 "들어가" 보이지 않게 됩니다.
- 생산·식량·연구·세금·습격 수치는 자동 테스트로만 확인했습니다. 실제 플레이 속도에 맞춘 밸런스 조정이 필요할 수 있습니다.
- 주민 32명 기준 게임 로직은 헤드리스에서 프레임당 약 0.7ms, 길 찾기 격자 생성은 약 20ms(건물이 바뀔 때만)였습니다. 주민 캐릭터 모델 렌더링 비용은 실제 GPU에서 확인이 필요합니다(110m 밖의 주민은 그리지 않음).
- 헤드리스 소프트웨어 렌더러에서는 매우 느립니다. 실제 GPU 기준의 성능은 사람이 직접 확인해야 합니다. 보통 품질 기준 약 460 드로우 콜, 100만 삼각형입니다.
- 세계 시드는 현재 하나로 고정되어 있습니다(구조는 시드별 생성을 지원).
